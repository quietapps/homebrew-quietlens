# Quiet Lens Homebrew tap

Homebrew tap for [Quiet Lens](https://github.com/quietapps/QuietLens) — a native macOS menu bar app that dims every window except the focused one.

## Install

```sh
brew tap quietapps/quietlens
brew install --cask quietlens
```

## Update

```sh
brew update
brew upgrade --cask quietlens
```

## Uninstall

```sh
brew uninstall --cask quietlens
brew untap quietapps/quietlens
```
